# Portofolio Rony Risvaldo

Ruang 3D dengan komputer jadul; layarnya menampilkan desktop retro (`static/os.html`) berisi profil, pengalaman, project, dan kontak.

- Ruang 3D: berbasis [portfolio-website](https://github.com/henryjeff/portfolio-website) karya Henry Heffernan, lisensi MIT (lihat `LICENSE.md`).
- Desktop retro di `static/os.html`: ditulis sendiri untuk portofolio ini.

## Menjalankan

```bash
npm install
npm run dev     # server pengembangan di http://localhost:8080
npm run build   # hasil statis di folder public/
```
